curl -X PUT -H "Content-Type: application/vnd.schemaregistry.v1+json" \
> --data '{"compatibility": "NONE"}' \
> http://<schema-registry-url>:<schema-registry-port>/config

Kafka Connect Rest Service (here host:port are kafka connect rest service)
Get list of connectors
curl http://host:port/connectors
Delete a connector
curl -X DELETE http://host:port/connectors/<connector-name>
Get connector configuration
curl http://host:port/connectors/<connector-name>
Get connector status
curl http://host:port/connectors/<connector-name>/status
Update Configuration of existing connector
curl -H "Content-Type: application/json" -X PUT-d @<path-to-file>/<file-name-with-json-extension> http://host:port/connectors/<connector-name>/config
Restart a conector
curl -X POST http://host:port/connectors/<connector-name>/restart
Pause a connector
curl -X PUT http://host:port/connectors/<connector-name>/pause
Resumt a connector
curl -X PUT http://host:port/connectors/<connector-name>/resume
Add a connector 
curl -H "Content-Type: application/json" -X POST -d @<path-to-file>/<file-name-with-json-extension> http://host:port/connectors
